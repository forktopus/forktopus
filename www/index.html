Все Git-репозитории на одном экране

Forktopus находит репозитории на диске и показывает по каждому ветку, незакоммиченные изменения, отставание от upstream, открытые PR/MR и CI на GitHub, GitLab и Gitea. Без аккаунта, без токенов, без скрытых операций.

Forktopus — приложение для компьютера. Откройте эту страницу на Linux, Windows или macOS либо выберите систему ниже.

Три взгляда на одни данные

Режимы переключаются мгновенно: фильтры, поиск и выбранный репозиторий общие.

Реестр — таблица всех репозиториев с сортировкой и фильтрами: требуют внимания, есть изменения, отстают, упал CI, нет данных PR/CI. Fetch и Pull — прямо из строки.

Проводник — дерево «корень → сервер → владелец → репозиторий» и подробная карточка: ветки, изменённые файлы, PR/MR, CI, кнопки «Показать в папке» и «Открыть в терминале».

Радар — карточки в трёх колонках: «Требует внимания» (конфликты, незавершённый merge, ошибки чтения), «В работе» и «В порядке». Сразу видно, куда смотреть.

Что умеет

Источник правды — сам git. Сведения о PR/MR и CI берутся из CLI, которые у вас уже установлены.

Находит репозитории

В выбранных папках на любой глубине, пропуская node_modules, vendor и похожие каталоги. Сервер определяется по git remote, а не по имени папки.

Ветки и изменения

Текущая ветка или detached HEAD, staged / unstaged / untracked, конфликты, незавершённые merge и rebase, ahead/behind по последнему fetch.

PR/MR и CI

Открытые PR/MR текущей ветки (а если их нет — последний влитый или закрытый) и итог CI на GitHub, GitLab и Gitea через gh, glab и gt.

Работает в фоне

Раз в несколько минут сам перечитывает статус и PR/CI, даже когда окно свёрнуто в трей. Может запускаться при входе в систему.

Уведомления о переменах

CI упал или снова проходит, ветка отстала от upstream, PR/MR открыт, влит или закрыт. Клик открывает карточку репозитория.

Диагностика CLI

Найден ли git, gh, glab, gt, авторизован ли и что выполнить в терминале. Нет CLI — локальная часть работает как обычно.

Монитор, а не ещё один Git-клиент

Forktopus работает локально и ничего не меняет без вашего подтверждения.

Делает — только при выполненных условиях

  • Fetch — git fetch --no-prune; удаление устаревших веток включается отдельно.
  • Pull — только fast-forward, после подтверждения и только на чистой ветке с upstream.
  • Switch — на существующую локальную ветку, после подтверждения и только на чистой рабочей копии.

Не делает никогда

  • Не коммитит и не делает push, reset, stash, rebase и force-операции.
  • Не пишет в .git/config, не создаёт и не удаляет ветки и папки.
  • Не спрашивает и не хранит токены и пароли, не требует аккаунта: авторизация остаётся в ваших CLI.
  • Не создаёт и не меняет PR/MR, не запускает CI.

macOS

Intel и Apple Silicon · .app в zip

Приложение не нотаризовано Apple, поэтому двойной щелчок его не откроет. Распакуйте архив и снимите карантин: xattr -cr forktopus.app.

Архив .zipuniversal

Forktopus использует CLI, которые уже установлены у вас:

  • git — обязателен: всё о локальных репозиториях Linux Windows macOS
  • gh — PR и CI на GitHub Linux Windows macOS
  • glab — MR и пайплайны на GitLab Linux Windows macOS
  • gt — PR и CI на Gitea (подойдёт и прежний tea) Linux Windows macOS

gh, glab и gt нужны только для своих серверов; авторизуйтесь в них как обычно — что выполнить, подскажет «Диагностика CLI». Без них Forktopus показывает всё, что знает локальный git.

Проверено на Ubuntu 24.04; на Windows 11 — локальная часть. Сборка для macOS на Mac пока не проверялась. Файлы не подписаны сертификатом; контрольные суммы — в SHA256SUMS на странице релиза.
