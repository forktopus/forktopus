# Правила для агентов

## Сообщения коммитов

- Формат — [Conventional Commits](https://www.conventionalcommits.org/): префикс `тип(область):` на английском (`feat`, `fix`, `chore`, `docs`, `test`, `perf`, `build`, `refactor`).
- Текст после префикса и тело — **на русском**.
- Коммиты — прямо в `main`.

Пример:

```text
feat(scan): поиск Git-репозиториев в корневых папках

- рекурсивный обход со списком пропусков, без симлинков и bare-репозиториев
- разбор remote URL, определение провайдера, выбор основного remote
```
